# Skills

Har bir yangi yaratilgan yoki qo'shilgan skill shu papkaga qo'shiladi.

- Fayl nomi kebab-case (masalan `git-operations.md`).
- Bir nechta bog'liq skill bo'lsa kategoriya papkasiga guruhlang: `skills/<kategoriya>/`.
- Har bir skill fayli boshida YAML frontmatter bo'lishi shart:

```yaml
---
skill: <skill-name>
name: <Human-Readable Name>
version: <semver>
description: <bir qatorli tavsif>
---
```
