# Bajarilgan Vazifalar (Completed Tasks)

> `task.md` dan bajarilgan vazifalar shu yerga ko'chiriladi. Bu yerdan hech narsa o'chirilmaydi.

## Format
```
### [Kategoriya] Vazifa nomi
- **Yaratilgan:** YYYY-MM-DD
- **Bajarilgan:** YYYY-MM-DD
- **Tavsif:** ...
```
